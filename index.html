How Wardrobe & JSON files work

What is a JSON file? It's a standard text-based format used to save and back up your wardrobe items.

How to get started:

  • Option A: You don't need any file to start! Browse the Encyclopedia and check off items you own. The site saves them automatically, and you can click Export JSON anytime to download your backup.
  • Option B (existing backup): If you already have a compatible wardrobe backup, click Import JSON here to load it instantly.

Need assistance? Community advice and game guides can be found on Reddit (r/LoveNikki) or community Discord servers.
